# SuiviEntretien

Application Android .NET MAUI pour noter les offres auxquelles tu postules et retrouver les détails quand un recruteur appelle.

## Première version

- Saisie rapide avec entreprise et poste obligatoires.
- Source, date, statut, recruteur, coordonnées, lien et notes.
- Recherche et filtre par statut.
- Compteurs des candidatures, attentes, entretiens et relances dues.
- Données enregistrées localement sur le téléphone.

Le workflow GitHub Actions construit un APK à chaque push sur `main`. Télécharge-le depuis les artefacts de l’exécution Actions.
